### Next.js Product Catalogue

A product catalogue web application built with Next.js and SQLite, featuring search, sorting, dynamic routing, and pagination for efficient product browsing.

## Features

- **Product Listing** — Display products retrieved from an SQLite database.
- **Search** — Find products by relevant keywords.
- **Sorting** — Organise products based on selected criteria.
- **Dynamic Routing** — Navigate between product categories and models.
- **Pagination** — Browse products across multiple pages.
- **Database Integration** — Store and retrieve product data using SQLite

## Tech Stack
- Next.js
- React
- SQLite
- TypeScript 


### Installation
 - npm install

  - npm run dev
